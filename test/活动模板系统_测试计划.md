## 五、API 回归测试（直接 fetch 调用）

Agent 可以在终端中直接运行以下测试（用 curl 或写脚本）：

```bash
# 测试模板列表 API
curl -b "session=<cookie>" http://localhost:3000/api/admin/activities/templates

# 测试模板详情 API
curl -b "session=<cookie>" http://localhost:3000/api/admin/activities/templates/<template_id>

# 测试创建模板
curl -X POST -b "session=<cookie>" \
  -H "Content-Type: application/json" \
  -d '{"name":"测试模板","maxScore":100}' \
  http://localhost:3000/api/admin/activities/templates

# 测试更新模板
curl -X PATCH -b "session=<cookie>" \
  -H "Content-Type: application/json" \
  -d '{"name":"改名后的模板","maxScore":80}' \
  http://localhost:3000/api/admin/activities/templates/<template_id>

# 测试创建项目
curl -X POST -b "session=<cookie>" \
  -H "Content-Type: application/json" \
  -d '{"templateId":"<template_id>","name":"测试项目","score":5}' \
  http://localhost:3000/api/admin/activities/items

# 测试更新项目
curl -X PATCH -b "session=<cookie>" \
  -H "Content-Type: application/json" \
  -d '{"name":"修改后","score":10}' \
  http://localhost:3000/api/admin/activities/items/<item_id>

# 测试删除项目
curl -X DELETE -b "session=<cookie>" \
  http://localhost:3000/api/admin/activities/items/<item_id>

# 测试创建分类
curl -X POST -b "session=<cookie>" \
  -H "Content-Type: application/json" \
  -d '{"templateId":"<template_id>","name":"测试分类"}' \
  http://localhost:3000/api/admin/activities/categories

# 测试删除分类
curl -X DELETE -b "session=<cookie>" \
  http://localhost:3000/api/admin/activities/categories/<category_id>

# 测试未登录请求
curl http://localhost:3000/api/admin/activities/templates
# 预期: 401 {"error":"未登录"}
```

> 获取 session cookie：先在浏览器中登录 `admin/admin123`，打开 F12 → Application → Cookies → 复制 `session` 的值
