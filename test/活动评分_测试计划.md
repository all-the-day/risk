## 五、API 测试脚本

Agent 可以在终端中直接运行：

```bash
# 获取 session cookie（先登录）
curl -X POST -c cookies.txt \
  -H "Content-Type: application/json" \
  -d '{"phone":"admin","password":"admin123"}' \
  http://localhost:3000/api/auth/login

# 获取活动模板
curl -b cookies.txt http://localhost:3000/api/activities/template

# 提交评分（需替换 item_id 为实际值）
curl -X POST -b cookies.txt \
  -H "Content-Type: application/json" \
  -d '{"scores":[{"itemId":"<item_id_1>","score":6},{"itemId":"<item_id_2>","score":5}]}' \
  http://localhost:3000/api/activities/score

# 查询当周记录
curl -b cookies.txt http://localhost:3000/api/activities/records

# 查询指定周记录
curl -b cookies.txt "http://localhost:3000/api/activities/records?week=2026-W24"

# 未登录测试
curl http://localhost:3000/api/activities/template
# 预期: 401 {"error":"未登录"}
```

> 获取 session cookie：先在浏览器中登录 `admin/admin123`，打开 F12 → Application → Cookies → 复制 `session` 的值

## 六、关键检查点

| 检查项 | 说明 |
|--------|------|
| 叶子项默认满分 | 所有叶子项输入框初始值为模板设定的满分 |
| 父项自动计算 | 修改子项分值后，父项分值自动更新为子项之和 |
| 总分实时更新 | 修改任意分值后，页面顶部总分即时变化 |
| 提交持久化 | 提交后刷新页面，分值保持不变 |
| 权限控制 | 未登录无法访问 API 和页面 |
| 底部导航 | "活动"导航项可正常跳转 |
| 无运行时错误 | 控制台无未捕获异常 |
