## A. 成员每天用的（前台）

| # | 功能 | 现在的样子 | 备注 |
|---|---|---|---|
| A1 | 登录 | 昵称+密码；手机号格式会被拒绝；管理员登录后直接进后台 | |
| A2 | 注册 | 昵称+密码+确认；注册完去「加入/创建家」 | |
| A3 | 加入家 / 创建家 | 输入邀请码加入；创建家的人自动成为「团长」 | |
| A4 | 今日打卡 | 只显示今天（不能补昨天、不能提前勾）；点一下=打卡，再点=取消 | |
| A5 | 打卡清单的分组 | 父项和分类只作标题、不可点；标题右边显示小计（已勾/总数） | |
| A6 | 打卡页进度 | 卡片顶部进度条 + 「已完成 n/m」；全部勾完出现祝贺卡 | |
| A7 | 事项上的次数提示 | 每项旁边标「周 3 次」这类提示文字 | |
| A8 | 周报告（周次） | 可多选周次（最近 8 周可选，默认本周） | |
| A9 | 周报告（总览卡） | 本家总分/满分、满分人数、进度条 | |
| A10 | 周报告（三种视图） | ①成员卡片（含多周小趋势）②图表（柱状/折线切换）③表格（姓名列固定+合计行） | |
| A11 | 周报告/团体页的可见性 | 团长和管理员看全家；普通成员只看自己（页面上有提示语） | |
| A12 | 团体页 | 本家今天每个人完成了多少项（进度条），没别的 | |
| A13 | 我的页 | 邀请码（可复制）、周报告入口、意见反馈、改家内昵称、退出团体、退出登录 | |
| A14 | 底部导航 | 四个 tab：今日 / 报告 / 团体 / 我的 | |

## B. 管理后台（侧栏 5 项）

| # | 功能 | 现在的样子 | 备注 |
|---|---|---|---|
| B1 | 周分录入 | 选一个家 + 多选周次（最近 6 周可选、默认最近 2 周）；表格里直接改数 | |
| B2 | 自动 / 已锁定 | 格子默认显示自打卡汇总（自动）；管理员录入后变「已锁定」；可「恢复自动」 | |
| B3 | 事项模板 | 新建/启用/删除模板；同时只有一个模板是启用状态 | |
| B4 | 模板详情 | 改名称、满分、描述；分类增删改；事项增删改（短名、全名、分值、每周次数、启用停用、父子两层） | |
| B5 | 事项排序 | 没有排序/拖拽功能，顺序固定 | |
| B6 | 团体管理 | 改名、重置邀请码、禁用/启用、删除、任命团长（一家唯一）、移除成员 | |
| B7 | 用户管理 | 新增账号、设为管理员/普通、重置密码、删除（不能操作自己） | |
| B8 | 反馈 | 看反馈、筛选（待处理/已处理）、标记状态、删除、复制 Prompt、导出 JSON | |
| B9 | 后台适配 | 电脑上左侧栏；手机上抽屉菜单 | |

## C. 规则口径（看不见，但决定怎么算）

| # | 规则 | 现在的样子 | 备注 |
|---|---|---|---|
| C1 | 单项得分 | 分值 ÷ 每周次数；做够次数满分，没做够按比例；做超了不额外加分 | |
| C2 | 一周的定义 | 周日 → 周六；未来的周不能选、不能录入 | |
| C3 | 周分怎么来 | 打开就按打卡实时算，不存历史快照 | |
| C4 | 管理员录入 | 录入即覆盖锁定；「恢复自动」= 删掉那条覆盖 | |
| C5 | 谁能看 | 团长/管理员看全家，成员只看自己 | |
| C6 | 打卡对象 | 只有叶子项能勾；父项只作分组；停用项不出现 | |
| C7 | 满分 50 | 周表分母固定取模板满分（当前 50） | |
