# 活动评分 — 用户使用指南

## 一、进入页面

1. 用 `admin` / `admin123` 登录
2. 点击底部导航栏的 **"活动"**
3. 进入 `/activities` 评分页面

---

## 三、操作说明

### 3.1 调整分值

- 每个 **叶子项目**（无子项的）旁有一个数字输入框
- 默认填的是满分，比如 CX 默认显示 `6`
- 如果实际完成度不够，可以直接点击输入框改成更低的分数
- 比如 CX 从 `6` 改为 `4`

### 3.2 父项自动汇总

- 带子项的项目（如"聚会"）**不可手动输入**
- 它的分值 = 子项之和（XP + ZR）
- 比如 XP 改成 `5`，ZR 改成 `6`，则聚会自动显示 `11`

### 3.3 总分实时变化

- 顶部 "当前 X 分" 会随着你修改分值实时更新
- 满分 51 表示所有项目满分时的总分

### 3.4 提交评分

1. 调整完分值后，点击底部蓝色的 **"提交评分"** 按钮
2. 提交成功会显示绿色提示：**"评分已保存"**（2 秒后自动消失）

### 3.5 查看历史

1. 点击右上角 **"历史记录"** 按钮
2. 展开历史面板，显示所有已评分的周次
3. 每行显示一个周的日期范围

### 3.6 修改已提交的分数

- 直接修改输入框中的数字
- 再次点击 **"提交评分"**
- 刷新页面后分数保持修改后的值

## 四、演示步骤（建议操作顺序）

1. 登录 → 点击底部 **"活动"**
2. 看到周评页面，所有分值默认满分（51分）
3. 将 **CX** 改为 `4`，观察总分变为 `49`
4. 将 **追求** 改为 `5`，观察总分变为 `48`
5. 将 **Gospel（福音）** 改为 `2`，观察总分变为 `47`
6. 注意 **聚会** 分值 14 不变（因为 XP、ZR 没改）
7. 点击 **"提交评分"**，看到绿色"评分已保存"
8. 刷新浏览器（F5），确认分值仍在
9. 点击右上角 **"历史记录"**，看到当周记录

## 五、数据说明

| 字段 | 说明 |
|------|------|
| 满分 | 所有项目都打满分时的总分，当前为 51 |
| 当前 | 当前输入框中的分值总和（实时变化） |
| / 后面的数 | 该项目的满分（提示你最高能打几分） |
| 蓝色数字（只读） | 父项，分值由子项自动汇总 |
| 白色输入框 | 叶子项，可以手动调整 |

## 六、常见问题

**Q: 为什么聚会不能输入？**
A: 聚会是父项，分值 = XP + ZR。修改 XP 和 ZR 的分值即可。

**Q: 提交后还能改吗？**
A: 可以。改完直接再点"提交评分"就行，会覆盖之前的记录。

**Q: 历史记录怎么切换周？**
A: 当前版本自动使用当周，无需手动切周。历史面板展示所有已评过的周次。

**Q: 每周什么时候能评分？**
A: 每周一至周日都可以评分，随时修改提交。
