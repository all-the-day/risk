# 项目管理（新一版）功能点 · 待你批注

> 后台「项目管理」页（`/admin/activities`）这一版做的全部功能点，逐条列出来。
> **批注方式**：在最后一列「你的备注」直接写（「对」「不要」「改成…」都行）；表格里不好写就在文末「备注区」写编号 + 想法。
> 带 ⚠️ 的是我自己觉得可疑、想听你意见的地方。

## A. 页面头部

| # | 功能点 | 现在的样子 | 你的备注 |
|---|---|---|---|
| A1 | 入口 | 后台侧栏「项目管理」（原来叫「事项模板」） | |
| A2 | 汇总信息 | 标题下显示「满分 X 分 · 叶子项合计 Y 分 · 共 N 项」 | |
| A3 | 模板选择 | 下拉切换模板；启用中的那个名字后面带「（启用中）」。⚠️ 只有一个模板时这个下拉是不是多余？ | |
| A4 | 设为启用 | 当前看的模板没启用时，出现「设为启用」按钮（同时只有一个启用） | |
| A5 | 新建模板 | 按钮 → 弹窗填名称即可（新模板初始 0 项、满分 0） | |
| A6 | 标签与模板信息 | 链接跳旧详情页（改模板名称/描述、增删改标签）。⚠️ 标签增删改还留在这里，要不要也搬进新页面？ | |
| A7 | 搜索 | 右上搜索框，按名称/全称过滤 | |

## B. 项目列表（表格）

| # | 功能点 | 现在的样子 | 你的备注 |
|---|---|---|---|
| B1 | 列 | 项目 / 分值 / 次数-周 / 允许勾选 / 类型 / 状态 / 操作 | |
| B2 | 项目名 | 点名称 = 打开只读「查看」；后面跟全称小字 | |
| B3 | 标签徽章 | 挂了标签的显示标签名（如「尽功用」） | 标签也不需要了，现在搞的太复杂 |
| B4 | 「分组」徽章 | 有子项的项目（如 聚会）标出来，子项缩进排在它下面 | 这个 分组不需要了，只需要，项目概念即可， |
| B5 | 分值 | 分组标题显示子项合计，自动维护（不能手改） | |
| B6 | 允许勾选 | 显示「不限」或「仅主日」 | 允许勾选这个字段有点奇怪，反正意思是允许打卡的日期，周内打卡限制类似这种，再简洁一点你想想看有没有 |
| B7 | 类型 | 个人 / 团体 徽章 | |
| B8 | 状态开关 | 点一下立刻启停 + 右上角提示（不用进表单） | |
| B9 | 上移 / 下移 | 同组内换顺序（⚠️ 跨组移动要改「归属」，没有拖拽） | |
| B10 | 编辑 | 打开抽屉表单（编辑态） | |
| B11 | 删除 | 弹确认框，说明「不再出现、满分重算、打卡记录一并删除」 | |
| B12 | 空状态 | 模板里没有项目时，显示引导 + 「新增项目」按钮 | |

## C. 抽屉表单（新增 / 编辑 / 查看三态共用）

| # | 功能点 | 现在的样子 | 你的备注 |
|---|---|---|---|
| C1 | 打开方式 | 头部「新增项目」/ 行内编辑图标 / 点名称=只读查看 | |
| C2 | 名称 | 必填（如 XP） | |
| C3 | 全称 | 可选（如 擘饼） | |
| C4 | 分值 | 该项每周满分；分组标题禁用（由子项合计） | |
| C5 | 每周次数 | 达到这个次数算满分，多做不额外加分 | |
| C6 | 允许勾选 | 不限 / **仅主日**（⚠️ 目前只有两档，将来要不要能选「周几」多选？） | |
| C7 | 类型 | 个人 / 团体 | |
| C8 | 归属 | 一个选择：无 / 分组标题（如 聚会）/ 标签（如 尽功用）—— ⚠️ 二选一，不能同时挂标签和分组 | |
| C9 | 启用 | 开关（停用=打卡页不出现、不计满分） | |
| C10 | 底部按钮 | 取消 / 保存（保存中显示转圈）；只读态只有「关闭」 | |
| C11 | 校验 | 名称必填、分值 ≥0 整数、次数 ≥1；错误用右上角提示，不弹窗 | |
| C12 | 保存后 | 自动刷新列表、右上角提示「已保存 / 已新增 X」 | |

## D. 规则生效（连带到其他页面的部分）

| # | 功能点 | 现在的样子 | 你的备注 |
|---|---|---|---|
| D1 | 打卡页过滤 | 「仅主日」的项目**只在主日出现**（今天周四 → 9 项里只出现 7 项） | |
| D2 | 服务端校验 | 就算绕过界面直接调接口，「仅主日」的项目非主日也会被拒 | |
| D3 | 团体页分母 | 「今日完成」的分母只算当天可勾项（不把主日项算进去） | |
| D4 | 满分自动重算 | 周表分母 = 启用项目之和；改分值/增删/停用后自动跟着变 | |
| D5 | 停用项目 | 打卡页不出现、不计满分；历史打卡记录保留 | |

## E. 我认为还可疑的地方（重点看这里）⚠️

| # | 问题 | 现状 | 你的意见 |
|---|---|---|---|
| E1 | 删除是硬删除 | 删项目会连带删它的历史打卡记录；要不要改成「只能停用、不能删」更安全？ | |
| E2 | 停用会让满分变小 | 比如停用 背经（4 分）→ 满分从 50 变 46，周表分母跟着变；已录入的周分不受影响 | |
| E3 | 团体DG 次数 | 纸表写「一周至少一次」，你之前备注说「三次满分」—— 现在是 **1 次**，界面上可改 | |
| E4 | XP 是否限主日 | 现在 XP **不限**（ZR、主日申言 才是仅主日） | |
| E5 | 个人/团体的划分 | 我按猜测设的：聚会、XP、ZR、团体DG = 团体；其余 = 个人 | |
| E6 | 「补勾」还没有 | 昨天漏勾了今天补不了（这块你之前问过，我还没做） | |
| E7 | 没有批量操作 | 一次只能改一个项目，没有多选批量启停/删除 | |
| E8 | 移动端形态 | 手机上抽屉是满宽面板；表格是横向滚动 | |
